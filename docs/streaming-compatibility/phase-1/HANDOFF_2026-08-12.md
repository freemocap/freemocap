## Non-negotiables

- **No backwards compatibility.** One version of the system: the current one. Nothing has shipped.
- **Fail loudly.** No silent skips, no defaults that quietly disable a feature.
- **No duplicated information.** Any fact stated twice is a bug.
- **skellyforge/skellytracker NEVER import from freemocap.** freemocap is the integration layer.
- Cross-repo: freemocap installs skellies **from git**. Local edits are invisible until **the user**
  commits + pushes, then `uv lock --upgrade-package <pkg>` && `uv sync`. **Never commit — the user owns git.**
- Vocabulary (doc 13 is SSOT): **keypoint** = tracked+triangulated (SkellyTracker). **landmark** = fitted
  point on a segment (SkellyForge). **segment** = VRM-1.0-aligned rigid body, *not* an anatomical bone.
- Canonical convention: **mm · right-handed · +Z up · +X forward**, quaternions **wxyz**, identity == T-pose.

## How to work here

Increment → verify → **update the plans in the same turn** (defect register + progress log). Write plans to
disk before coding; the folder's rule is "no code until the plan is agreed." Ask when a decision is the
user's — anatomy, data-model shape, scope. Test before fixing: for D1 the failing test decided the
convention rather than ratifying a guess.

**Testing discipline (doc 14):** a test must be able to fail for the reason it exists. Three ways a
parent/child rotation pair goes order-blind: uniform bend, either side at rest orientation, coaxial
rotations. All three are guard tests now. Assert against closed-form envelopes, not hand-picked tolerances.
