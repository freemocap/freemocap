# API notes

The old route sketch and proposed redesign have been superseded by the accepted
integration. Use the maintained [API boundary](/docs/architecture/api-boundary)
and [WebSocket contract](/docs/architecture/backend-websocket-server).

Do not copy historical `/mocap`, `/exports/scientific` or recording `/playback`
aliases into a new client. Canonical recording resources, exports and task lifecycle
now use the reconciled routes. Compatibility aliases remain documented in the
repository's route migration inventory.
