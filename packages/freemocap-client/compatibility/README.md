# Compatibility evidence

Each development/release version records its reviewed server baseline, OpenAPI and
source fingerprints, runtime versions, tests actually run and limitations. An
application version string or WebSocket shape version alone is not an HTTP API
fingerprint. Update the ledger and independent expectations deliberately when the
accepted server contract changes; do not regenerate scientific expected values
from decoder output.

`0.1.0-dev.0.json` records the current unpublished package. Raw local evidence lives
under the Core checkout's `.test-artifacts/w6`; the JSON retains portable results
and source hashes without embedding private recording data. No future client,
engine connector or output adapter is implied by these results.
